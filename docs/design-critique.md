# Design Critique: 태산입시 (2026-10-28, 개편 전)

### Overall Impression
네이버 카페 구조(왼쪽 카페 정보·게시판 목록, 오른쪽 본문)는 학부모에게 익숙해서 맞는 선택이다. 다만 덧칠한 스타일이 여섯 겹 쌓여 있어 같은 종류의 요소가 화면마다 다르게 생겼고, 이모지 아이콘·그라데이션 배너·친근한 말투가 "AI가 만든 템플릿" 인상을 준다. 가장 큰 개선 지점은 **하나의 디자인 시스템으로 다시 짓는 것**이다.

### Usability
| Finding | Severity | Recommendation |
|---------|----------|----------------|
| 모바일 상단에 로고가 두 번(위 줄 + 배너) 나와 첫 화면의 절반을 차지, 글 목록이 접힘 아래로 밀림 | 🔴 Critical | 모바일 배너를 얇은 띠로 줄이고 로고는 한 번만 |
| 게시판 메뉴가 데스크탑은 왼쪽 목록, 모바일은 가로 탭 + 하단 앱 메뉴 잔재 등 진입점이 화면마다 다름 | 🟡 Moderate | 데스크탑: 왼쪽 목록 / 모바일: 상단 가로 탭 한 가지로 통일 |
| 글쓰기 버튼(FAB)이 데스크탑에서 본문 밖 오른쪽에 떠 있어 표의 마지막 열과 겹쳐 보임 | 🟡 Moderate | 데스크탑은 게시판 제목 옆 "글쓰기" 버튼, FAB는 모바일만 |
| 신고 사유를 브라우저 prompt 창으로 받음 | 🟡 Moderate | 사유 선택형 대화상자 |
| 빈 상태 문구가 화면마다 크기·여백이 다름 | 🟢 Minor | 공통 빈 상태 컴포넌트 |

### Visual Hierarchy
- **What draws the eye first**: 파란 그라데이션 배너와 흰 붓글씨 로고 — 정체성은 드러나지만 정작 주인공인 글 목록보다 무겁다.
- **Reading flow**: 배너 → 왼쪽 버튼 두 개(진한 회색) → 본문. 진한 회색 "가입하기"가 브랜드색보다 강해 시선이 왼쪽으로 새어 나간다.
- **Emphasis**: 말머리 태그가 게시판마다 다른 색(주황·보라·초록·파랑·노랑)이라 목록이 알록달록해지고 제목보다 태그가 먼저 읽힌다.

### Consistency
| Element | Issue | Recommendation |

| 글자 크기 | 11.5·12·12.5·13·13.5·14·14.5·15·15.5·16·17px 등 11가지 | 12·13·14·15·17·20·24·32 여덟 단계 |
| 둥글기 | 2·3·4·6·8·10·12·14·16·18·22px, 999px 혼용 | 컨트롤 8px, 카드 12px, 태그 4px 세 가지 |
| 버튼 | 알약형·사각형·진회색·남색·회색이 화면마다 섞임 | Primary(남색)·Secondary(테두리)·Ghost(글자) 세 종류 |
| 색 | 남색 외 주황·보라·초록·빨강·노랑 태그색, 회색이 #333/#444/#555/#666/#777/#888/#999 | 회색 9단계 + 남색 한 가지, 경고만 빨강 |
| 말투 | "반가워요 👋", "올렸어요!", "가입을 환영해요!" | 짧고 담백한 안내형 문장 |

### Accessibility
- **Color contrast**: 연회색 보조 글자(#9aa0a8 on #fff)가 2.6:1로 기준 미달 → 보조 글자 #6B7684(4.6:1) 이상.
- **Touch targets**: 관리자 숨김·삭제 버튼, 쪽 번호가 30px 미만 → 모바일 최소 40px.
- **Text readability**: 모바일 목록 메타 글자 11~12px → 13px, 본문 줄간격 1.7 유지.

### What Works Well
- 네이버 카페식 정보 구조(왼쪽 목록, 표 목록, 쪽 번호, 기간·범위 검색)는 학부모가 바로 이해한다.
- 비회원 제목 보기, 게시판별 공지 고정, 관리자 숨김·삭제 등 운영 기능은 이미 갖춰져 있다.

### Priority Recommendations
1. **디자인 시스템 재구축** — 글자 크기·간격·색·둥글기를 토큰으로 정하고 CSS를 처음부터 다시 쓴다(덧칠 6겹 제거).
2. **이모지 → SVG 아이콘, 말머리 단색화** — AI 템플릿 인상을 만드는 가장 큰 원인 제거.
3. **배너·헤더 재설계** — 로고 한 번, 배너는 차분한 단색 + 얇은 높이, 모바일 첫 화면에 목록이 보이게.
4. **말투 정리** — 안내 문구를 짧고 사실 위주로.
5. **글꼴** — Wanted Sans(원티드랩, OFL)를 자체 호스팅해 기기 간 모양을 통일.
