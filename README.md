# 태산입시

대전 학생과 학부모가 입시 정보와 고민을 나누는 회원 전용 커뮤니티입니다(운영: 태산학원). **사이트: https://taesan.uinone.net**

- 빌드 없이 동작하는 정적 사이트(HTML + ES 모듈), 글꼴은 Wanted Sans(OFL)
- 서버: **AWS**(Cognito 로그인·휴대폰 인증, DynamoDB, Lambda + HTTP API, S3, CloudFront). 배포 방법은 [docs/aws-deploy.md](docs/aws-deploy.md)
- `public/js/aws-config.js`가 비어 있는 동안은 예전 서버(Firebase)를 씁니다.

## 화면

| 주소 | 내용 |
| --- | --- |
| `#/` | 홈: 공지, 인기글 순위, 소식·입시·수다·학교 새 글, 자료실 새 자료 |
| `#/community/rec`, `#/community/all` | 인기글(최근 7일 반응 순), 전체글 |
| `#/community/news·talk·school·admission` | 게시판: 말머리 탭, 표 목록(말머리·제목·작성자·작성일·조회·좋아요), 게시판 공지 고정, 쪽 번호, 기간·범위 검색 |
| `#/study` | 자료실: 직접 만들었거나 허락받은 자료만, 관리자 승인 후 공개 |
| `#/notices` | 공지사항 |
| `#/post/{id}` | 글 보기: 사진·첨부, 좋아요, 댓글(사진 1장)·댓글 좋아요, 신고 |
| `#/search`, `#/notifications`, `#/me`, `#/menu` | 검색, 알림, 내 정보(보기·비밀번호 변경·탈퇴), 전체 메뉴 |
| `#/admin` | 관리자: 회원 관리, 글 관리, 배너 |

문제풀이 게시판(답변 채택)은 만들어 두었고, 학생 회원이 모이면 `config.js`의 `QNA_OPEN = true`로 엽니다.

## 회원·개인정보

- 가입 항목: 아이디, 비밀번호, 실명, 휴대폰(인증번호 문자), 성별, 나이, 학생/학부모(학년 또는 자녀 학년). 이용규칙·개인정보 동의 필수, 만 14세 미만은 보호자 동의 필수.
- 같은 휴대폰 번호로는 한 계정만 만들 수 있습니다.
- 실명·휴대폰·성별·나이는 **본인과 관리자만** 봅니다. 다른 회원에게는 닉네임·학년만 보입니다.
- 본인 정보는 고칠 수 없고(학원 문의), 비밀번호 변경과 탈퇴만 할 수 있습니다.
- 비회원은 글 제목 목록까지만 보고, 내용·댓글·파일은 회원만 봅니다.

## 관리자

- 회원 정보의 권한이 `admin`인 계정입니다. 첫 관리자는 `bash aws/scripts/create-admin.sh qwer`로 만들고, 그 뒤에는 관리자 화면에서 지정합니다.
- 회원 관리: 개인정보 전체 보기, 이용 정지·해제, 관리자 지정·해제. 글 작성자를 누르면 그 회원 정보가 바로 열립니다.
- 글 관리: 모든 글 옆 숨김·삭제, 자료 승인·반려, 신고 처리, 공지 쓰기, 배너(표지 제목·설명·배경 사진) 바꾸기.
- 정지된 회원은 읽기만 할 수 있습니다.
- 광고: 홈 가운데·오른쪽 태산학원 광고 문구를 고치고 추가·삭제·순서 변경. 저장 전에는 `public/js/ads.js` 기본 광고가 나옵니다.
- AI 광고 초안: 매주 월요일 오전 9시, 태산학원 밴드 최근 2주 글로 AI(Claude)가 광고 초안을 만듭니다. 관리자가 '광고' 칸에서 불러와 확인하고 저장해야 게시됩니다. 키는 CloudShell에서 `bash aws/scripts/set-ai-keys.sh`로 넣습니다(밴드 Access Token, Claude API 키 → SSM 암호화 저장). 키가 없으면 건너뜁니다.

## 서버 규칙

권한 규칙은 `aws/api/core.mjs` 한 파일에 있습니다. Lambda(`aws/api/index.mjs`)와 체험 모드가 같은 파일을 씁니다(`public/js/server-core.js`는 복사본, `scripts/sync-core.sh`로 맞춤).

```bash
cd aws/api && npm ci && cd ../.. && node --test aws/api/test/*.test.mjs
```

## 체험 모드

주소 뒤에 `?demo=1`을 붙이면 서버 없이 그 브라우저 안에서 같은 서버 규칙으로 동작합니다. 인증번호는 `123456`, 아이디 `admin`으로 가입하면 관리자가 됩니다.

```bash
python3 -m http.server 5173 --directory public   # http://localhost:5173/?demo=1
```

## 데이터 구조(DynamoDB 표 1개)

| 키(pk / sk) | 내용 |
| --- | --- |
| `U#회원` / `PROFILE` | 아이디·닉네임·학년·권한·정지 |
| `U#회원` / `PRIVATE` | 실명·휴대폰·성별·나이·구분·보호자 동의 |
| `U#회원` / `N#알림` | 댓글·채택·자료 승인 알림(180일 뒤 자동 삭제) |
| `NICK#닉네임`, `PHONE#번호` | 닉네임·휴대폰 중복 방지 |
| `P#글` / `META` | 제목·말머리·작성자·조회·좋아요·댓글 수·공개 상태(목록 색인) |
| `P#글` / `BODY` | 본문·사진·첨부·출처 |
| `P#글` / `C#댓글`, `L#회원`, `CL#회원#댓글` | 댓글, 글 좋아요, 댓글 좋아요 |
| `R#신고`, `BANNER` / `cover`·`ads`, `F#파일` | 신고, 표지·안내 띠·광고 목록, 첨부 파일 정보 |
| `ADSDRAFT` / `latest` | AI 광고 초안(관리자만 봄) |

목록 색인: `gsi1` 게시판별·승인 대기·숨김·신고, `gsi2` 전체 공개 글·회원 목록, `gsi3` 회원별 글, `gsi4` 게시판+말머리.

## 예전 서버(Firebase)

`firestore.rules`, `scripts/*.py`는 Firebase를 쓰던 때의 파일입니다. AWS로 완전히 옮긴 뒤 지울 예정입니다.
